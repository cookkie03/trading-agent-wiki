# datapizza-ai
**Build reliable Gen AI solutions without overhead**
`datapizza-ai` provides clear interfaces and predictable behavior for agents and RAG. End-to-end visibility and reliable orchestration keep engineers in control from PoC to scale
## Installation
Install the library using pip:

```
[](https://docs.datapizza.ai/0.1.0/#__codelineno-0-1)pip install datapizza-ai

```

## Key Features
  * **Integration with AI Providers** : Seamlessly connect with AI services like OpenAI and Google VertexAI.
  * **Complex workflows, minimal code.** : Design, automate, and scale powerful agent workflows without the overhead of boilerplate.
  * **Retrieval-Augmented Generation (RAG)** : Enhance AI responses with document retrieval.
  * **Faster delivery, easier onboarding for new engineers** : Rebuild a RAG + tools agent without multi-class plumbing; parity with simpler, typed interfaces.
  * **Up to 40% less debugging time** : Trace and log every LLM/tool call with inputs/outputs


## Quick Start
To get started with `datapizza-ai`, ensure you have Python `>=3.10.0,<3.13.0` installed.
Here's a basic example demonstrating how to use agents in `datapizza-ai`:

```
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-1)from datapizza.agents import Agent
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-2)from datapizza.clients.openai import OpenAIClient
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-3)from datapizza.tools import tool
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-4)
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-5)@tool
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-6)def get_weather(city: str) -> str:
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-7)    return f"The weather in {city} is sunny"
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-8)
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-9)client = OpenAIClient(api_key="YOUR_API_KEY")
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-10)agent = Agent(name="assistant", client=client, tools = [get_weather])
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-11)
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-12)response = agent.run("What is the weather in Rome?")
[](https://docs.datapizza.ai/0.1.0/#__codelineno-1-13)# output: The weather in Rome is sunny

```
