## Overview
This tool provides a robust and easy-to-use interface for `datapizza-ai` agents to perform various operations on the local file system. This includes listing, reading, writing, creating, deleting, moving, copying, and precisely replacing content within files.
> **⚠️ Warning: Risk of Data Loss and System Modification**
> Operations performed by this tool directly affect your local file system. Using functions like `delete_file`, `delete_directory`, and `write_file` can lead to permanent data loss or unintended system modifications if not used carefully. Exercise extreme caution.
## Features
  * **List directories** : `list_directory(path: str)`
  * **Read files** : `read_file(file_path: str)`
  * **Write files** : `write_file(file_path: str, content: str)`
  * **Create directories** : `create_directory(path: str)`
  * **Delete files** : `delete_file(file_path: str)`
  * **Delete directories** : `delete_directory(path: str, recursive: bool = False)`
  * **Move or rename** : `move_item(source_path: str, destination_path: str)`
  * **Copy files** : `copy_file(source_path: str, destination_path: str)`
  * **Replace with precision** : `replace_in_file(file_path: str, old_string: str, new_string: str)` - Replaces a block of text only if it appears exactly once, requiring context in `old_string` for safety.


## Usage Example

```

[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-2)import tempfile
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-3)import shutil

[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-5)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-6)# Initialize the tool
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-7)fs_tool = FileSystem()
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-8)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-9)# Create a temporary directory for the example
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-10)temp_dir_path = tempfile.mkdtemp()
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-11)print(f"Working in temporary directory: {temp_dir_path}")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-12)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-13)# 1. Create a directory
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-14)fs_tool.create_directory(os.path.join(temp_dir_path, "my_folder"))
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-15)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-16)# 2. Write a file
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-17)fs_tool.write_file(os.path.join(temp_dir_path, "my_folder", "my_file.txt"), "Hello, world!\nAnother line.")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-18)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-19)# 3. Replace content precisely
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-20)# The 'old_string' should be unique to avoid errors.
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-21)fs_tool.replace_in_file(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-22)    os.path.join(temp_dir_path, "my_folder", "my_file.txt"),
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-23)    old_string="Hello, world!",
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-24)    new_string="Goodbye, world!"
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-25))
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-26)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-27)# 4. Read the file to see the change
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-28)content = fs_tool.read_file(os.path.join(temp_dir_path, "my_folder", "my_file.txt"))
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-29)print(f"File content: {content}")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-30)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/filesystem/#__codelineno-1-31)# Clean up the temporary directory

```
