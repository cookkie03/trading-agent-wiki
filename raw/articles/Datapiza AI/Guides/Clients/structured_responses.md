# MCPClient
##  datapizza.tools.mcp_client.MCPClient
Helper for interacting with Model Context Protocol servers.
Can be used in two modes:
  1. **Stateless mode** (default): Each operation creates a new session. Good for HTTP-based MCP servers that don't require persistence.



```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-0-1)client = MCPClient(url="https://example.com/mcp")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-0-2)tools = client.list_tools()
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-0-3)# Each tool call creates a new session

```

  1. **Persistent mode** : Use as an async context manager to keep the session alive across multiple operations. Required for stdio-based servers or servers that maintain state.



```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-1-1)async with MCPClient(command="uvx", args=["my-mcp-server"]) as client:
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-1-2)    tools = await client.a_list_tools()
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-1-3)    # All tool calls share the same session
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-1-4)    agent = Agent(tools=tools)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Tools/mcp/#__codelineno-1-5)    await agent.a_run("do something")

```
