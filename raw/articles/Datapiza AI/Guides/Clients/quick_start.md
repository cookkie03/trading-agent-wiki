# Streaming
Streaming allows you to receive responses in real-time as they're generated, providing a better user experience for long responses and interactive applications.
## Why Use Streaming?
  * **Real-time feedback** : Users see responses as they're generated
  * **Better UX** : Reduces perceived latency for long responses
  * **Progressive display** : Show partial results immediately
  * **Interruptible** : Can stop generation early if needed


## Basic Streaming
### Synchronous Streaming

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-1)from datapizza.clients.openai import OpenAIClient
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-2)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-3)client = OpenAIClient(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-4)    api_key="your-api-key",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-5)    model="gpt-4o-mini"
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-6))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-7)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-8)# Basic streaming
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-9)for chunk in client.stream_invoke("Write a short story about a robot learning to paint"):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-10)    if chunk.delta:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-11)        print(chunk.delta, end="", flush=True)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-0-12)print()  # New line when complete

```

### Asynchronous Streaming

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-1)import asyncio
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-2)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-3)async def async_stream_example():
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-4)    async for chunk in client.a_stream_invoke("Explain quantum computing in simple terms"):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-5)        if chunk.delta:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-6)            print(chunk.delta, end="", flush=True)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-7)    print()  # New line when complete
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-8)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-9)# Run the async function
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/#__codelineno-1-10)asyncio.run(async_stream_example())

```
