# Real example: Chatbot
Learn how to build conversational AI applications using the OpenAI client with memory management, context awareness, and advanced chatbot patterns.
## Basic Chatbot
Clients need memory to maintain context and have meaningful conversations. The Memory class stores and manages conversation history, allowing the AI to reference previous exchanges and maintain coherent dialogue.
Here's a simple example of a chatbot with memory:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-1)from datapizza.clients.openai import OpenAIClient
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-2)from datapizza.memory import Memory
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-3)from datapizza.type import ROLE, TextBlock
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-4)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-5)client = OpenAIClient(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-6)    api_key="your-api-key",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-7)    model="gpt-4o-mini",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-8)    system_prompt="You are a helpful assistant"
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-9))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-10)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-11)def simple_chatbot():
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-12)    """Basic chatbot with conversation memory."""
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-13)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-14)    memory = Memory()
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-15)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-16)    print("Chatbot: Hello! I'm here to help. Type 'quit' to exit.")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-17)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-18)    while True:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-19)        user_input = input("\nYou: ")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-20)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-21)        if user_input.lower() in ['quit', 'exit', 'bye']:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-22)            print("Chatbot: Goodbye!")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-23)            break
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-24)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-25)        # Get AI response with memory context
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-26)        response = client.invoke(user_input, memory=memory)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-27)        print(f"Chatbot: {response.text}")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-28)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-29)        # Update conversation memory
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-30)        memory.add_turn(TextBlock(content=user_input), role=ROLE.USER)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-31)        memory.add_turn(response.content, role=ROLE.ASSISTANT)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-32)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-33)# Run the chatbot
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/#__codelineno-0-34)simple_chatbot()

```
