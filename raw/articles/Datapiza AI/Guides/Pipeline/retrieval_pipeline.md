##  datapizza.clients.openai.OpenAIClient
Bases: `Client[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/clients/#datapizza.core.clients.client.Client "datapizza.core.clients.client.Client \(datapizza.core.clients.Client\)")`
A client for interacting with the OpenAI API.
This class provides methods for invoking the OpenAI API to generate responses based on given input data. It extends the Client class.
