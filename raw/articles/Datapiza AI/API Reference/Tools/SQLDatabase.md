# DoclingParser
A document parser that uses Docling to convert PDF files into structured hierarchical Node representations with preserved layout information and media extraction.
## Installation

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-0-1)pip install datapizza-ai-parsers-docling

```

## Usage

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-1-1)from datapizza.modules.parsers.docling import DoclingParser
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-1-2)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-1-3)# Basic usage
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-1-4)parser = DoclingParser()
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-1-5)document_node = parser.parse("sample.pdf")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-1-6)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-1-7)print(document_node)

```

## Parameters
  * `json_output_dir` (str, optional): Directory to save intermediate Docling JSON results for debugging and inspection


## Features
  * **PDF Processing** : Converts PDF files using Docling's DocumentConverter with OCR and table structure detection
  * **Hierarchical Structure** : Creates logical document hierarchy (document → sections → paragraphs/tables/figures)
  * **Media Extraction** : Extracts images and tables as base64-encoded media with bounding box coordinates
  * **Layout Preservation** : Maintains spatial layout information including page numbers and bounding regions
  * **Markdown Generation** : Converts tables to markdown format and handles list structures
  * **Metadata Rich** : Preserves full Docling metadata in `docling_raw` with convenience fields


## Configuration
The parser automatically configures Docling with:
  * Table structure detection enabled
  * Full page OCR with EasyOCR
  * PyPdfium backend for PDF processing

### Basic Document Processing

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-1)from datapizza.modules.parsers.docling import DoclingParser
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-2)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-3)parser = DoclingParser()
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-4)document = parser.parse("research_paper.pdf")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-5)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-6)# Access hierarchical structure
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-7)for section in document.children:
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-8)    print(f"Section: {section.metadata.get('docling_label', 'Unknown')}")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-9)    for child in section.children:
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-10)        if child.node_type.name == "PARAGRAPH":
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-11)            print(f"  Paragraph: {child.content[:100]}...")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-12)        elif child.node_type.name == "TABLE":
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-13)            print(f"  Table with {len(child.children)} rows")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-14)        elif child.node_type.name == "FIGURE":
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-2-15)            print(f"  Figure: {child.metadata.get('docling_label', 'Image')}")

```

### Tesseract Language Options
When using Tesseract OCR, you can specify languages in the `tesseract_lang` parameter as a list:
**Single Language:**

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-4-1)ocr_config = OCROptions(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-4-2)    engine=OCREngine.TESSERACT,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-4-3)    tesseract_lang=["eng"],  # English
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-4-4))

```

**Multiple Languages:**

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-5-1)ocr_config = OCROptions(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-5-2)    engine=OCREngine.TESSERACT,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-5-3)    tesseract_lang=["eng", "ita", "fra"],  # English, Italian, French
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-5-4))

```

**Automatic Language Detection:**

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-6-1)ocr_config = OCROptions(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-6-2)    engine=OCREngine.TESSERACT,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-6-3)    tesseract_lang=["auto"],  # Auto-detect language
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/#__codelineno-6-4))

```

**Common Language Codes:** - `"eng"` - English - `"ita"` - Italian - `"fra"` - French - `"deu"` - German - `"spa"` - Spanish - `"por"` - Portuguese - `"chi_sim"` - Simplified Chinese - `"chi_tra"` - Traditional Chinese - `"jpn"` - Japanese - `"auto"` - Automatic detection
For a complete list of supported languages, refer to [Tesseract documentation](https://github.com/UB-Mannheim/tesseract/wiki).
