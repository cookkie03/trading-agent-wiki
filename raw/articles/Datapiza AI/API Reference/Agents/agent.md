# Structured Responses
Generate structured, typed data from AI responses using Pydantic models. This ensures consistent output format and enables easy data validation.
## Basic Usage
### Simple Model

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-1)from datapizza.clients.openai import OpenAIClient
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-2)from pydantic import BaseModel
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-3)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-4)client = OpenAIClient(api_key="your-api-key", model="gpt-4o-mini")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-5)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-6)class Person(BaseModel):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-7)    name: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-8)    age: int
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-9)    occupation: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-10)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-11)response = client.structured_response(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-12)    input="Create a profile for a software engineer",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-13)    output_cls=Person
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-14))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-15)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-16)person = response.structured_data[0]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-17)print(f"Name: {person.name}")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-18)print(f"Age: {person.age}")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-0-19)print(f"Occupation: {person.occupation}")

```

### Complex Models

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-1)from typing import List
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-2)from pydantic import BaseModel, Field
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-3)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-4)class Product(BaseModel):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-5)    name: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-6)    price: float = Field(gt=0, description="Price must be positive")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-7)    tags: List[str]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-8)    in_stock: bool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-9)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-10)class Store(BaseModel):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-11)    name: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-12)    location: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-13)    products: List[Product]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-14)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-15)response = client.structured_response(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-16)    input="Create a tech store with 3 products",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-17)    output_cls=Store
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-18))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-19)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-20)store = response.structured_data[0]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-21)print(f"Store: {store.name}")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-22)for product in store.products:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-1-23)    print(f"- {product.name}: ${product.price}")

```

## Data Extraction
### Extract Information from Text

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-1)class ContactInfo(BaseModel):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-2)    name: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-3)    email: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-4)    phone: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-5)    company: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-6)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-7)text = """
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-8)Hi, I'm John Smith from TechCorp.
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-9)You can reach me at john.smith@techcorp.com or call 555-0123.
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-10)"""
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-11)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-12)response = client.structured_response(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-13)    input=f"Extract contact information from this text: {text}",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-14)    output_cls=ContactInfo
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-15))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-16)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-17)contact = response.structured_data[0]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-2-18)print(f"Contact: {contact.name} at {contact.company}")

```

### Analyze and Categorize

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-1)from enum import Enum
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-2)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-3)class Sentiment(str, Enum):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-4)    POSITIVE = "positive"
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-5)    NEGATIVE = "negative"
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-6)    NEUTRAL = "neutral"
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-7)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-8)class TextAnalysis(BaseModel):
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-9)    sentiment: Sentiment
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-10)    confidence: float = Field(ge=0, le=1)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-11)    key_topics: List[str]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-12)    summary: str
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-13)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-14)review = "This product is amazing! Great quality and fast shipping."
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-15)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-16)response = client.structured_response(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-17)    input=f"Analyze this review: {review}",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-18)    output_cls=TextAnalysis
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-19))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-20)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-21)analysis = response.structured_data[0]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-22)print(f"Sentiment: {analysis.sentiment}")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-23)print(f"Confidence: {analysis.confidence}")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/structured_responses/#__codelineno-3-24)print(f"Topics: {', '.join(analysis.key_topics)}")

```
