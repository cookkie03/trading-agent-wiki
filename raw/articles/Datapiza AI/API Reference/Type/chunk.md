## Usage

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-1)from datapizza.embedders.fastembedder import FastEmbedder
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-2)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-3)embedder = FastEmbedder(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-4)    model_name="Qdrant/bm25",
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-5)    embedding_name="bm25_embeddings",
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-6))
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-7)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-8)# Embed text (returns sparse embeddings)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-9)embeddings = embedder.embed(["Hello world", "Another text"])
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Embedders/fast_embedder/#__codelineno-1-10)print(embeddings)

```

## Features
  * Uses FastEmbed for efficient sparse text embeddings
  * Local model execution (no API calls required)
  * Configurable model caching directory
  * Custom embedding naming
  * Sparse embedding format for memory efficiency
  * Both sync and async embedding support
