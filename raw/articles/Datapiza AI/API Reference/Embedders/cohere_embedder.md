# Client Factory
The ClientFactory provides a convenient way to create LLM clients for different providers without having to import and instantiate each client type individually.
##  datapizza.clients.factory.ClientFactory
Factory for creating LLM clients
###  create `staticmethod`

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-1)create(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-2)    provider,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-3)    api_key,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-4)    model,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-5)    system_prompt="",
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-6)    temperature=0.7,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-7)    **kwargs
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/client_factory/#__codelineno-0-8))

```

Create a client instance based on the specified provider.
Parameters:  
| Name  | Type  | Description  | Default  |  
| --- | --- | --- | --- |  
|  `provider`  |  `str | Provider`  |  The LLM provider to use (openai, google, or anthropic)  |  _required_  |  
|  `api_key`  |  `str`  |  API key for the provider  |  _required_  |  
|  `model`  |  `str`  |  Model name to use (provider-specific)  |  _required_  |  
|  `system_prompt`  |  `str`  |  System prompt to use  |  `''`  |  
|  `temperature`  |  `float`  |  Temperature for generation (0-2)  |  `0.7`  |  
|  `**kwargs`  |   |  Additional provider-specific arguments  |  `{}`  |  
Returns:  
| Type  | Description  |  
| --- | --- |  
|  `Client[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/clients/#datapizza.core.clients.client.Client "datapizza.core.clients.client.Client")`  |  An instance of the appropriate client  |  
Raises:  
| Type  | Description  |  
| --- | --- |  
|  `ValueError`  |  If the provider is not supported  |
