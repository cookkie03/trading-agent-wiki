# Rerankers
Rerankers are pipeline components that reorder and score retrieved content based on relevance to a query. They improve retrieval quality by applying more sophisticated ranking algorithms after initial retrieval, helping surface the most relevant content for user queries.
## Installation
All rerankers require separate installation via pip and are not included by default with `datapizza-ai-core`.
## Available Rerankers
### Optional Rerankers (Separate Installation Required)
  * [CohereReranker](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/cohere_reranker/) - Uses Cohere's reranking API for high-quality semantic reranking
  * [TogetherReranker](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/together_reranker/) - Uses Together AI's API with various model options


## Common Features
  * High-quality semantic reranking using specialized models
  * Configurable result count and score thresholds
  * Support for both sync and async processing
  * Automatic relevance scoring for retrieved content
  * Integration with various reranking model providers


## Usage Patterns
### Basic Reranking Pipeline

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-1)from datapizza.modules.rerankers.cohere import CohereReranker
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-2)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-3)reranker = CohereReranker(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-4)    api_key="your-cohere-key",
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-5)    endpoint="https://api.cohere.ai/v1",
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-6)    top_n=5,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-7)    threshold=0.6
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-8))
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-9)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-10)query = "What is deep learning?"
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-0-11)reranked_chunks = reranker(query, chunks)

```

### RAG Pipeline Integration

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-1)from datapizza.modules.rerankers.together import TogetherReranker
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-2)from datapizza.vectorstores import QdrantVectorStore
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-3)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-4)# Initial broad retrieval
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-5)vectorstore = QdrantVectorStore(collection_name="documents")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-6)initial_results = vectorstore.similarity_search(query, k=20)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-7)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-8)# Rerank for better relevance
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-9)reranker = TogetherReranker(api_key="together-key", model="rerank-model")
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Rerankers/#__codelineno-1-10)reranked_results = reranker(query, initial_results)

```

## Best Practices
  1. **Choose the Right Model** : Select reranker models based on your domain and language requirements
  2. **Tune Thresholds** : Experiment with relevance score thresholds to balance precision and recall
  3. **Initial Retrieval Size** : Retrieve more documents initially (k=20-50) before reranking to improve final quality
  4. **Performance Considerations** : Use async processing for high-throughput applications
  5. **Cost Management** : Monitor API usage, especially for high-volume applications
  6. **Evaluation** : Test different rerankers on your specific data to find the best performance
