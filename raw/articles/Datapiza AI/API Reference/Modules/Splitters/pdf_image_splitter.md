# Quick Start
This guide will help you get started with the `OpenAIClient` in datapizza-ai. For specialized topics, check out our detailed guides on [multimodality](https://docs.datapizza.ai/0.1.0/Guides/Clients/multimodality/), [streaming](https://docs.datapizza.ai/0.1.0/Guides/Clients/streaming/) and [building chatbots](https://docs.datapizza.ai/0.1.0/Guides/Clients/chatbot/).
## Installation
First, make sure you have datapizza-ai installed:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-0-1)pip install datapizza-ai

```

## Basic Setup

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-1)from datapizza.clients.openai import OpenAIClient
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-2)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-3)# Initialize the client with your API key
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-4)client = OpenAIClient(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-5)    api_key="your-openai-api-key",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-6)    model="gpt-4o-mini",  # Default model
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-7)    system_prompt="You are a helpful assistant",  # Optional
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-8)    temperature=0.7  # Optional, controls randomness (0-2)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-1-9))

```


```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-2-1)# Basic text response
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-2-2)response = client.invoke("What is the capital of France?")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-2-3)print(response.text)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-2-4)# Output: "The capital of France is Paris."

```

## Working with Memory
Memory allows you to maintain conversation context:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-1)from datapizza.memory import Memory
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-2)from datapizza.type import ROLE, TextBlock
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-3)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-4)memory = Memory()
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-5)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-6)# First interaction
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-7)response1 = client.invoke("My name is Alice", memory=memory)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-8)memory.add_turn(TextBlock(content="My name is Alice"), role=ROLE.USER)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-9)memory.add_turn(response1.content, role=ROLE.ASSISTANT)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-10)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-11)# Second interaction - the model remembers Alice
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-12)response2 = client.invoke("What's my name?", memory=memory)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/quick_start/#__codelineno-5-13)print(response2.text)  # Should mention Alice

```

