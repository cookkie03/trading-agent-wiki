# Parsers
Parsers are pipeline components that convert documents into structured hierarchical Node representations. They extract text, layout information, and metadata from various document formats to create tree-like data structures for further processing.
Each parser should return a [Node](https://docs.datapizza.ai/0.1.0/API%20Reference/Type/node/) object, which is a hierarchical representation of the document content.
If you write a custom parser that returns a different type of object (for example, the plain text of the document content), you must use a [TreeBuilder](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/treebuilder/) to convert it into a Node.
## Available Parsers
### Core Parsers (Included by Default)
  * [TextParser](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/text_parser/) - Simple text parser for plain text content


### Optional Parsers (Separate Installation Required)
  * [AzureParser](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/azure_parser/) - Azure AI Document Intelligence parser for PDFs and documents
  * [DoclingParser](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/docling_parser/) - Docling-based parser for PDFs with layout preservation and media extraction


## Common Usage Patterns
### Basic Text Processing

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-0-1)from datapizza.modules.parsers.text_parser import parse_text
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-0-2)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-0-3)# Process plain text
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-0-4)document = parse_text("Your text content here")

```

### Document Processing Pipeline

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-1)from datapizza.modules.parsers import TextParser
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-2)from datapizza.modules.splitters import RecursiveSplitter
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-3)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-4)# Create processing pipeline
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-5)parser = TextParser()
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-6)splitter = RecursiveSplitter(chunk_size=1000)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-7)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-8)# Process document
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-9)document = parser.parse(text_content)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Modules/Parsers/#__codelineno-1-10)chunks = splitter(document.content)

```
