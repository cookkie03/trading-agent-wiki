##  datapizza.clients.google.GoogleClient
Bases: `Client[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/clients/#datapizza.core.clients.client.Client "datapizza.core.clients.client.Client \(datapizza.core.clients.Client\)")`
A client for interacting with Google's Generative AI APIs.
This class provides methods for invoking the Google GenAI API to generate responses based on given input data. It extends the Client class.

## Thinking Configuration
Gemini models support explicit reasoning via `thinking_config`. Use `include_thoughts=True` to receive `ThoughtBlock` in the response.
### Gemini 2.5 – Budget-based thinking

```
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-1)response = client.invoke(
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-2)    input="Explain step by step why the sky is blue.",
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-3)    thinking_config={
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-4)        "thinking_budget": 1024,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-5)        "include_thoughts": True,
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-6)    },
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-7))
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-8)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-9)print("Thoughts:", response.thoughts)
[](https://docs.datapizza.ai/0.1.0/API%20Reference/Clients/Avaiable_Clients/google/#__codelineno-2-10)print("Answer:", response.text)

```

## Native Tools
