# Running with Ollama
Datapizza AI supports running with local models through Ollama, providing you with complete control over your AI infrastructure while maintaining privacy and reducing costs.
## Prerequisites
Before getting started, you'll need to have Ollama installed and running on your system.
### Installing Ollama
  1. **Download and Install Ollama**
  2. Visit [ollama.ai](https://ollama.ai) and download the installer for your operating system
  3. Follow the installation instructions for your platform
  4. **Start Ollama Service**

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-0-1)# Ollama typically starts automatically after installation
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-0-2)# If not, you can start it manually:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-0-3)ollama serve

```

  5. **Pull a Model**

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-1)# Pull the Gemma 2B model (lightweight option)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-2)ollama pull gemma2:2b
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-3)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-4)# Or pull Gemma 7B for better performance
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-5)ollama pull gemma2:7b
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-6)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-7)# Or pull Llama 3.1 8B
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-1-8)ollama pull llama3.1:8b

```



## Installation
Install the Datapizza AI OpenAI-like client:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-2-1)pip install datapizza-ai-clients-openai-like

```

## Basic Usage
Here's a simple example of how to use Datapizza AI with Ollama:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-1)import os
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-2)from datapizza.clients.openai_like import OpenAILikeClient
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-3)from dotenv import load_dotenv
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-4)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-5)load_dotenv()
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-6)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-7)# Create client for Ollama
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-8)client = OpenAILikeClient(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-9)    api_key="",  # Ollama doesn't require an API key
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-10)    model="gemma2:2b",  # Use any model you've pulled with Ollama
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-11)    system_prompt="You are a helpful assistant.",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-12)    base_url="http://localhost:11434/v1",  # Default Ollama API endpoint
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-13))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-14)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-15)# Simple query
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-16)response = client.invoke("What is the capital of France?")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/local_model/#__codelineno-3-17)print(response.content)

```
