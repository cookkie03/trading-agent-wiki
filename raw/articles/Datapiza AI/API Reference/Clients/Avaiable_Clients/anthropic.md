# Tools
Tools allow AI models to call external functions, enabling them to perform actions, retrieve data, and interact with external systems.
## Basic Tool Usage
### Simple Tool

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-1)from datapizza.clients.openai import OpenAIClient
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-2)from datapizza.tools import tool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-3)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-4)client = OpenAIClient(api_key="your-api-key", model="gpt-4o-mini")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-5)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-6)@tool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-7)def get_weather(location: str) -> str:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-8)    """Get the current weather for a location."""
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-9)    # Simulate weather API call
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-10)    return f"The weather in {location} is sunny and 72°F"
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-11)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-12)# Use the tool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-13)response = client.invoke(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-14)    "What's the weather in New York?",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-15)    tools=[get_weather]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-16))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-17)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-18)# Execute tool calls
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-19)for func_call in response.function_calls:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-20)    result = func_call.tool(**func_call.arguments)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-21)    print(f"Tool result: {result}")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-22)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-0-23)print(response.text)

```

### Multiple Tools

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-1)@tool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-2)def calculate(expression: str) -> str:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-3)    """Calculate a mathematical expression."""
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-4)    try:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-5)        result = eval(expression)  # Note: Use safe evaluation in production
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-6)        return str(result)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-7)    except Exception as e:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-8)        return f"Error: {e}"
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-9)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-10)@tool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-11)def get_time() -> str:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-12)    """Get the current time."""
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-13)    from datetime import datetime
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-14)    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-15)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-16)# Use multiple tools
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-17)response = client.invoke(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-18)    "What time is it and what's 15 * 8?",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-19)    tools=[get_time, calculate]
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-20))
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-21)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-22)# Execute all tool calls
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-23)for func_call in response.function_calls:
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-24)    result = func_call.tool(**func_call.arguments)
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-1-25)    print(f"{func_call.name}: {result}")

```

## Tool Choice Control
### Auto (Default)
Let the model decide when to use tools:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-2-1)response = client.invoke(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-2-2)    "Hello, how are you?",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-2-3)    tools=[get_weather],
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-2-4)    tool_choice="auto"  # Model may or may not use tools
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-2-5))

```

### Required
Force the model to use a tool:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-3-1)response = client.invoke(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-3-2)    "Get weather information",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-3-3)    tools=[get_weather],
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-3-4)    tool_choice="required"  # Model must use a tool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-3-5))

```

### None
Disable tool usage:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-4-1)response = client.invoke(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-4-2)    "What's the weather like?",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-4-3)    tools=[get_weather],
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-4-4)    tool_choice="none"  # Model won't use tools
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-4-5))

```

### Specific Tool
Force a specific tool:

```
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-5-1)response = client.invoke(
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-5-2)    "Check the weather",
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-5-3)    tools=[get_weather, get_time],
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-5-4)    tool_choice=["get_weather"]  # Only use this specific tool
[](https://docs.datapizza.ai/0.1.0/Guides/Clients/tools/#__codelineno-5-5))

```
