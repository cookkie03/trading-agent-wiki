## Perché questo modello è legale

Il punto chiave è che **è la piattaforma a pagare te**, non i tuoi amici. Tu non gestisci i loro soldi — loro scelgono liberamente di copiarti tramite un sistema regolamentato. La piattaforma è l'intermediario autorizzato. È un modello completamente diverso da quello di prima.

## eToro — La Scelta Principale

### Pro Investor Program

eToro paga fino all'**1.5% degli Asset Under Copy (AUC)** mensili ai trader del programma (tier Champion e superiori).

La formula è: `X% × AUC medio mensile ÷ 12`. Il programma è selettivo — meno del 20% dei candidati viene accettato.

**Requisiti minimi per entrare:**

- Account attivo da almeno 2 mesi
- Equity > $1.000
- Risk score ≤ 7 per 6 mesi
- Profilo completo (foto, bio 150+ parole)
- Almeno 1 copier

### 🤖 La cosa più interessante per te: Agent Portfolios + API

eToro ha lanciato gli **Agent Portfolios** — portfolio dedicati con API key scopate, collegabili a qualsiasi cosa tu abbia costruito: script Python, agenti LLM, bot di trading custom. Esempi reali: un agente che monitora il VIX via API esterna e ruota in posizioni difensive quando supera 25, girando autonomamente su un portfolio da $1.000.

La **Public API di eToro** supporta: trading algoritmico con esecuzione ordini a bassa latenza, analytics sui Pro Investor, streaming real-time di prezzi (crypto, azioni, ETF, commodities), gestione automatizzata del portfolio.

L'accesso all'API è stato inizialmente riservato proprio ai Popular Investor — il che crea un **flywheel perfetto per te**: diventi Pro Investor → colleghi il bot → le performance attraggono copier → l'AUC cresce → i pagamenti crescono.

## Alternative Valide

### ZuluTrade

ZuluTrade permette ai Signal Provider di mandare e gestire segnali tramite un proprio programma di trading che comunica con la piattaforma via **ZuluTrade API** — esattamente quello che faresti con il tuo bot Python.

Il vantaggio è che ZuluTrade si connette a **broker di tua scelta** già esistenti (AvaTrade, FXCM, ecc.), quindi non sei vincolato a un unico broker.

NAGA offre oltre 800 strumenti tradabili tra forex, crypto, azioni di NYSE/NASDAQ, indici, commodities ed ETF, con funzione **AutoCopy** per replicare automaticamente le operazioni dei trader. Buon ecosistema, meno dominante di eToro però.

## Analisi dei Candidati

### 🥇 Interactive Brokers (IBKR)

**Il broker più completo in assoluto per scalabilità**

La TWS API di Interactive Brokers rimane l'opzione più completa per i trader algoritmici seri: supporta oltre 150 tipi di ordine su 150 mercati in 34 paesi, con latenza media di esecuzione sotto i 50ms.

Sul fronte Python: `ib_insync` (ora fork `ib_async`) è una libreria matura — la maggior parte dei casi edge ha già risposte su StackOverflow. Il wrapper async è eccellente per workflow asincroni. Un dettaglio chiave: l'account reale usa la **stessa API** dell'account paper, quindi puoi sviluppare su paper e passare a live cambiando una riga di config.

Il flusso di setup è: apri account → scarica TWS o IB Gateway → abilita API nelle impostazioni → `pip install ib_insync` → connetti alla porta 7497 per il paper trading.

**Asset supportati**: Stocks, ETF, Options, Futures, Forex, Fixed Income, CFD, Crypto — praticamente tutto.

**Limite**: nessun copy trading nativo integrato.

---

### 🥈 Alpaca Markets

**Il migliore per iniziare oggi su US stocks**

Alpaca è il miglior punto di partenza gratuito per Python developer: offre trading di azioni e crypto commission-free, paper trading illimitato e un'interfaccia REST/WebSocket ben documentata senza saldo minimo richiesto.

L'SDK Python ufficiale `alpaca-py` copre Market Data API (real-time + storico per equity, crypto e options), Trading API e paper trading gratuito per tutti gli utenti. Si integra nativamente con Backtrader, Vectorbt e FinRL.

**Limite critico per te**: Alpaca al momento accetta clienti US per i live account, e soprattutto **non ha copy trading** — è puro broker API. Ottimo per la fase 1, ma non scala verso il tuo obiettivo finale.

---

### 🥉 eToro

**Il migliore per copy trading, API in crescita**

Come visto prima, eToro ha lanciato gli Agent Portfolios con API key dedicate, collegabili a script Python, agenti LLM o bot custom.

L'accesso all'API è stato inizialmente riservato ai Popular Investor — il che crea un flywheel interessante.

**Limite**: l'API è **recente e meno matura** rispetto a IBKR o Alpaca. Per un progetto serio di gestione portfolio algoritmico, è ancora acerba.

## Snippet Python di Confronto

**Alpaca (oggi, semplice):**

```python
from alpaca.trading.client import TradingClient
from alpaca.trading.requests import MarketOrderRequest
from alpaca.trading.enums import OrderSide, TimeInForce

client = TradingClient('API_KEY', 'SECRET_KEY', paper=True)

order = client.submit_order(MarketOrderRequest(
    symbol="AAPL",
    qty=10,
    side=OrderSide.BUY,
    time_in_force=TimeInForce.DAY
))
```

**IBKR (domani, potente):**

```python
from ib_async import IB, Stock, MarketOrder

ib = IB()
ib.connect('127.0.0.1', 7497, clientId=1)

contract = Stock('AAPL', 'SMART', 'USD')
order = MarketOrder('BUY', 10)
trade = ib.placeOrder(contract, order)

# Stesso codice funziona per Forex, ETF europei, Futures...
contract_eu = Stock('AIR', 'SBF', 'EUR')  # Airbus su Euronext
```
